AWS 建立IAM管理員帳號並避免使用root帳號登入

在 AWS 中，建立獨立的 IAM 管理員帳號並停止使用 Root 帳號進行日常操作，是 AWS 官方強烈建議的首要資安最佳實踐（Best Practices）[1]。

操作步驟

步驟 1：使用 Root 帳號登入並啟用 MFA

  1. 瀏覽 AWS 管理主控台，選擇 根使用者 (Root user) 並輸入 Email 登入。
  2. 進入 IAM 主控台（搜尋欄輸入 IAM）。
  3. 在儀表板右側點擊 新增 MFA，使用手機 App（如 Google Authenticator）完成綁定。

步驟 2：建立管理員使用者群組 (Group)

  1. 在 IAM 主控台左側選單點擊 使用者群組 (User groups)。
  2. 點擊 建立群組 (Create group)。
  3. 輸入群組名稱（例如：Admin-Group）。
  4. 在「許可政策 (Permissions policies)」列表中，搜尋並勾選 AdministratorAccess。
  5. 點擊 建立群組。

步驟 3：建立 IAM 管理員帳號並加入群組

  1. 在左側選單點擊 使用者 (Users) ＞ 建立使用者 (Create user)。
  2. 輸入使用者名稱（例如：aws-admin）。
  3. 勾選 提供使用者 AWS 管理主控台存取權。
  4. 選擇 我想建立 IAM 使用者，並設定密碼（建議勾選「在下次登入時要求建立新密碼」）。
  5. 點擊下一步，在「權限選項」中選擇 將使用者加入群組。
  6. 勾選剛剛建立的 Admin-Group。
  7. 點擊下一步，確認無誤後點擊 建立使用者。
  8. 重要：下載 .csv 檔案，儲存該帳號的專屬登入連結與憑證。

步驟 4：為新管理員帳號啟用 MFA

  1. 登出 Root 帳號。
  2. 點擊剛才儲存的專屬登入連結（或輸入帳戶 ID），使用新建立的 aws-admin 帳號登入。
  3. 登入後，進入 IAM ＞ 使用者 ＞ 點擊自己的使用者名稱。
  4. 切換到 安全性憑證 (Security credentials) 頁籤。
  5. 在「指派 MFA 裝置」區塊點擊 指派 MFA 裝置，完成手機綁定。

後續重要安全設定

  • 鎖定 Root 憑證：完成上述步驟後，請將 Root 帳號的密碼與 MFA 實體（如備用手機或硬體金鑰）鎖在安全的地方，僅在需要修改帳單、變更 AWS 方案或關閉帳戶時才使用。
  • 設定密碼原則：在 IAM 主控台的「帳戶設定 (Account settings)」中，強制執行複雜度要求（如長度、特殊字元）並定期更換。

如何更改區域為東京區並在此租用一個windows server

這是 AWS 主主控台（AWS Console）中的應用程式管理介面。要將區域更改為東京並建立一台 Windows Server 雲端伺服器（EC2），請按照以下步驟操作：

第一步：將區域更改為東京

目前您的區域設定在雪梨（ap-southeast-2）。

  1. 點擊區域下拉選單：點擊圖片左上角顯示 ap-southeast-2 (目前... 的藍色箭頭下拉框。
  2. 切換至東京：在彈出的區域列表中，搜尋並選擇 東京（Tokyo），對應的代碼為 ap-northeast-1。

第二步：租用 Windows Server (EC2)

變更區域至東京後，您需要使用 AWS EC2 服務來租用 Windows 伺服器：

  1. 進入 EC2 服務：在網頁最頂端的搜尋欄輸入 EC2 並點擊進入。
  2. 啟動執行個體：進入 EC2 儀表板後，點擊橘色的 啟動執行個體 (Launch Instance) 按鈕。
  3. 設定伺服器參數：
  • 名稱：為您的伺服器輸入一個辨識名稱。
  • 應用程式和作業系統映像 (AMI)：在快速啟動標籤頁中點擊 Windows，並在下拉選單選擇您需要的版本（例如：Microsoft Windows Server 2022 Base）。
  • 執行個體類型：若是測試用途，可選擇支援免費方案（Free tier eligible）的 t2.micro 或 t3.micro。
  • 金鑰對 (Key pair)：點擊「建立新金鑰對」，下載並妥善儲存 .pem 或 .ppk 檔案（此檔案用於日後取得 Windows 登入密碼）。
  • 網路設定：勾選「允許來自任何地方的 RDP 流量」，以便後續遠端連線。
  1. 啟動：確認右側面板的詳細資訊後，點擊 啟動執行個體 (Launch Instance)。

第三步：連線至您的 Windows 伺服器

  1. 等待伺服器啟動：在 EC2 執行個體列表中，等待該伺服器的狀態顯示為「執行中 (Running)」。
  2. 取得密碼：勾選該伺服器，點擊上方的 連線 (Connect) -> 選擇 RDP 用戶端 -> 點擊 取得密碼 -> 上傳您剛剛下載的金鑰檔案 -> 點擊 解密密碼。
  3. 遠端登入：複製畫面上的「公有 IP」與「密碼」，打開您電腦的「遠端桌面連線 (RDP)」應用程式，輸入 IP、帳號（通常為 Administrator）和密碼即可連線使用。

clone專案

第一步：在 Windows Server 安裝 Git

  1. 開啟瀏覽器：在伺服器中開啟 Edge 瀏覽器。
  2. 下載 Git：前往 Git 官方網站，點擊下載 64-bit Git for Windows Setup。
  3. 進行安裝：執行下載的 .exe 安裝檔，全部點擊「Next（下一步）」維持預設設定，直到安裝完成。
  4. 驗證安裝：
  • 在桌面空白處點擊滑鼠右鍵，選擇 Git Bash Here（或在開始功能表搜尋 Git Bash 開啟）。
  • 輸入命令：git --version
  • 若顯示版本號（例如 git version 2.x.x）即代表安裝成功。

第二步：將原本電腦的專案「推上」雲端平台

如果您目前的專案只存在您原本的本機電腦中，請先在原本的電腦上，將它推送到 GitHub 等平台：

  1. 建立雲端倉庫：登入您的 GitHub 帳號，點擊 New 建立一個新的 Repository（建議設為 Private 隱私）。

在原電腦關聯並推送：打開您原電腦的專案資料夾（使用終端機或 Git Bash），依序輸入以下指令：
bash
git remote add origin https://github.com

git branch -M main

git push -u origin main

  1. 請謹慎使用程式碼。

第三步：在 Windows Server 「複製（Clone）」專案

當專案已經在雲端平台上後，就可以在 Windows Server 上將它下載下來：

做法 A：使用 HTTPS 連線（最簡單、適合新手）

  1. 在 Windows Server 上建立一個用來放專案的資料夾。
  2. 在該資料夾內按右鍵開啟 Git Bash。

輸入下載指令（請將網址替換為您的 GitHub 專案網址）：
bash
git clone https://github.com

  1. 請謹慎使用程式碼。
  2. 驗證身份：此時畫面會彈出視窗，要求您登入 GitHub 帳號，或者要求輸入 Personal Access Token (PAT)。完成驗證後，專案就會成功下載到這台伺服器上。

做法 B：使用 SSH 金鑰連線（適合長期自動化部署）

如果您不希望每次都輸入密碼，可以設定 SSH 金鑰：

產生金鑰：在伺服器的 Git Bash 中輸入：
bash
ssh-keygen -t ed25519 -C "您的Email"

  1. 請謹慎使用程式碼。
    （連續按 Enter 即可，不用輸入密碼）

複製公鑰：輸入以下指令查看並複製整段代碼：
bash
cat ~/.ssh/id_ed25519.pub

  1. 請謹慎使用程式碼。
  2. 貼至 GitHub：前往 GitHub 網頁 -> Settings -> SSH and GPG keys -> New SSH Key，將剛剛複製的內容貼上並儲存。
  3. 複製專案：回到伺服器資料夾，使用 SSH 網址進行 Clone：
    bash
    git clone git@github.com:您的帳號/您的專案名稱.git

還原專案運行環境

當您把 Git 專案 Clone（複製）到伺服器後，還需要安裝該專案所需的 Python 依賴套件。

  1. 在 cmd 或 PowerShell 中，使用 cd 指令進入您下載下來的專案資料夾。
  2. 安裝專案套件：如果您的專案原本有匯出套件清單（通常命名為 requirements.txt），請執行以下指令自動安裝所有需要的套件：
    cmd
    pip install -r requirements.txt

讓server端web開放外網連線

必須把程式碼中的監聽地址從限制本機的 127.0.0.1（或 localhost），改成允許所有外網連線的 0.0.0.0。

修改方式取決於您是用 Flask 還是 Uvicorn (FastAPI) 開發。請根據您的後端框架，找到程式碼最後面負責「啟動服務」的那一行（通常在 if __name__ == '__main__': 底下）進行修改：

情況 A：如果您使用的是 Flask

請在專案的啟動檔案（通常是 app.py 或 main.py）中，找到 app.run()，修改為：

python

if __name__ == '__main__':

    # 舊的寫法可能是 app.run() 或 app.run(host='127.0.0.1')

    # 請修改為下方這行：

    app.run(host='0.0.0.0', port=5000)

請謹慎使用程式碼。

情況 B：如果您使用的是 Uvicorn (FastAPI)

請在啟動檔案中找到 uvicorn.run()，修改為：

python

import uvicorn

if __name__ == '__main__':

    # 請確保 host 參數設定為 '0.0.0.0'

    uvicorn.run("main:app", host='0.0.0.0', port=8000, reload=True)

請謹慎使用程式碼。

(注意："main:app" 請替換成您實際的檔案名稱與變數名稱)

💡 修改後的下一步：AWS 的安全組（Security Group）設定

程式碼改完後，這台 Windows Server 已經具備接收外網連線的能力了。但因為您使用的是 AWS，您還必須去 AWS 主控台調整防火牆，否則連線一樣會被擋下：

  • 步驟：進入 AWS EC2 主控台 ＞ 點選您的 Windows 執行個體 ＞ 切換到 安全性 (Security) 頁籤 ＞ 點擊進入 安全組 (Security Group)。
  • 設定：編輯「內送規則 (Inbound rules)」，新增一條規則：
  • 類型：自訂 TCP (Custom TCP)
  • 連接埠範圍：輸入您程式碼設定的 Port（例如 5000 或 8000）
  • 來源：選擇 0.0.0.0/0（代表允許任何地方連入）
  • 驗證

步驟 1：獲取 AWS Windows 伺服器的「公有 IP」

  1. 回到 AWS EC2 主控台，點擊左側選單的 執行個體 (Instances)。
  2. 勾選您那台 Windows Server 執行個體。
  3. 在下方詳細資訊面板中，找到 公有 IPv4 地址 (Public IPv4 address)。
  4. 將那串 IP 複製下來（例如：54.23.45.67）。

步驟 2：在您「原本的電腦」上進行測試

請確保 Windows Server 上的程式（Flask 或 Uvicorn）此時正在執行中，然後在您自己原本的本機電腦上，打開瀏覽器或使用 API 測試工具（如 Postman）。

根據您的框架，在網址列輸入以下對應網址：

  • 如果是 Flask：
    http://您的公有IP:5000 （例如：http://54.23.45.67:5000）
  • 如果是 Uvicorn (FastAPI)：
    http://您的公有IP:8000 （例如：http://54.23.45.67:8000）

防火牆問題

解決步驟：在 Windows 遠端伺服器內設定

1. 打開 Windows 防火牆設定

  1. 在 Windows Server 內的左下角搜尋欄，輸入 防火牆。
  2. 點選並打開 「具有進階安全性的 Windows 防火牆」（Windows Defender Firewall with Advanced Security）。

2. 新增「輸入規則」（Inbound Rules）

  1. 點擊左側選單的 「輸入規則」 (Inbound Rules)。
  2. 點擊右側選單的 「新規則...」 (New Rule...)。

3. 依序填入規則設定

  • 規則類型：選擇 「連接埠」 (Port) ＞ 點擊下一步。
  • 通訊協定與連接埠：選擇 TCP，並在「特定本機連接埠」輸入 5000 ＞ 點擊下一步。
  • 動作：選擇 「允許連線」 (Allow the connection) ＞ 點擊下一步。
  • 設定檔：將「網域」、「專用」、「公用」三個全部勾選 ＞ 點擊下一步。
  • 名稱：自訂一個名字，例如 Flask-5000 ＞ 點擊完成。
